# 리뷰기반의 커뮤니티 웹 서비스 
### 설명
이 프로젝트는 에이콘 아카데미에서 작업한 프로젝트로 9명이 만들었습니다.
## 기술 스택
- FrontEnd : React, Typescript, Bootstrap, Axios
- BackEnd : Java17, SpringBoot, Spring Security(JWT), JPA, MyBatis, Swagger
- DataBase : OracleDB
- Infra & Tools : Git/Github, Eclipse, IntelliJ, VSCode, ERDCloud, Figma, AWS EC2
  
관리자용 유저, 관리자용 예약 관련 코드를 담당하였습니다.
